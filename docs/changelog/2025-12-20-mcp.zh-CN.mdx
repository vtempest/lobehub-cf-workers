# MCP 云端点与模型库扩展 🔌

## 新功能

- **托管 MCP 云端点。** 支持市场集成，无需为每个工具自行托管 —— 直接从市场连接托管端点，在一处扩展可用工具集。
- **新增 AI 服务商。** **ZenMux**、**Nano Banana Pro** 与**七牛云**为请求路由和模型评估提供更多选择。
- **知识库支持创建页面。** 以层级结构组织信息，不再局限于扁平的文件结构。
- **文件管理与 RAG 搜索改进。** 日常查阅更可靠。
- **OIDC 与桌面端登录优化。** 认证流程与桌面登录体验在跨设备场景下更顺畅。
- **话题超链接。** 对话中可直接链接到话题。
- **消息编辑与删除。** 编辑和删除消息的行为更符合预期。

## 体验优化

- **话题列表交互。** 列表操作更顺手。
- **工具调用显示。** 工具调用内容更易读。
- **富文本编辑。** 编辑行为进一步完善。
- **Token 使用统计动画。** 统计动画得到优化。
- **模型选择器排序。** 模型排列更合理。
