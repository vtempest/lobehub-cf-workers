# LobeHub v1.6: GPT-4o Mini Joins the Default Lineup

## Features

- **GPT-4o mini support.** OpenAI's full model family has moved to GPT-4, and v1.6 follows by adding GPT-4o mini to the supported models.
- **GPT-4o mini as the Cloud default.** LobeHub Cloud replaces GPT-3.5-turbo with GPT-4o mini, so conversations start stronger from the first message with no configuration change.
- **GPT-4-level intelligence at a smaller scale.** Fast enough for real-time interaction and capable enough for everyday drafting, analysis, coding help, and creative work — better reasoning than GPT-3.5 without the latency of full GPT-4o, a cost-effective default for high-volume conversations, and strong instruction following and tool use.
- **Full capability still one switch away.** Move to full GPT-4o, Claude 3.5 Sonnet, or Gemini 1.5 Pro when a task needs maximum capability.
- **Automatic Cloud upgrade.** New conversations start on GPT-4o mini and the model switcher shows the new default first, so existing users change nothing. Cloud now offers GPT-4o mini (default), GPT-4o, Claude 3.5 Sonnet, and Gemini 1.5 Pro.

## Improvements

- **GPT-4o mini configuration.** Model configuration and parameter defaults ship with the model.
- **Cloud default model logic updated.** Default model selection picks up the new lineup.
- **Recommended options stand out.** The model switcher highlights recommended models.

## Fixes

- **Streaming edge cases on newer OpenAI models.** Streaming responses no longer break in those cases.
