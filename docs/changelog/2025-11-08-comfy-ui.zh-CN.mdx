# ComfyUI 集成与知识库优化 ⭐

## 新功能

- **对话中运行 ComfyUI 工作流。** 以往使用 ComfyUI 进行图像或视频生成的团队需要维护独立环境，现在现有的可视化流程可直接在对话上下文中执行。
- **PDF 文档导出。** 便于将对话归档以满足合规需求，或向需要离线副本的利益相关者分享结构化输出。
- **知识库瀑布流布局。** 浏览海量文件资源时扫读更高效。
- **上传时自动解压。** 直接拖拽 ZIP 文件，系统自动解压，省去导入前手动解压的步骤。
- **新增服务商。** **Cerebras** 与 **CometAPI** 加入阵容。
- **图像生成能力扩展。** 支持**硅基流动**与**混元 Text-to-Image 3**。
- **模型库更新。** 新增 **Claude Haiku 4.5**、**GPT-5 Pro**、**MiniMax-M2** 及 Vertex AI 的 **Imagen 4**。

## 体验优化

- **富文本链接渲染。** 链接展示更准确。
- **搜索体验。** 搜索更快、结果更易读。
- **可禁用富文本编辑。** 新增关闭富文本编辑器的选项。
- **删除与重新生成快捷键。** 两个操作都有了键盘快捷键。
- **更新通知行为。** 更新提示的打扰更少。
