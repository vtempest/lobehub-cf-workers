# 从任意消息创建对话分支

## 新功能

- **从任意消息创建分支。** 对话很少保持线性 —— 顺着某个话题深入、尝试不同思路，或把线程拆分给不同对象，都不会破坏原对话。
- **延续模式。** 保留完整对话历史并从该点继续，适合在保留上下文的同时探索「如果这样做会怎样」的场景。
- **独立模式。** 从选定消息开始全新的对话，适合提取干净的子对话或准备专注的节选用于分享。
- **原对话保持完整。** 点击消息上的分支按钮即可开启新线程，源对话不受影响。
- **在话题侧边栏切换分支。** 对比结果，并继续最有价值的那条路径。

对分支对话有改进建议？欢迎在 [GitHub Discussions](https://github.com/lobehub/lobe-chat/discussions) 分享。
