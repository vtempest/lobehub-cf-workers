# LobeHub v2.0 🎉

## 新功能

- **多智能体群聊。** 不必再让一个 Agent 包办所有任务，可以在同一会话里让多个专业 Agent 围绕同一目标讨论和推理。
- **智能体构建器。** 用自然语言描述目标，一次生成包含工具、行为、技能和个性的完整 Agent。
- **发布、改造与采用 Agent。** 可发布到应用市场、采用社区模板，或把 Agent 直接纳入 Workspace 持续迭代。
- **Pages 文档能力。** 在知识工作流中编写和整理文档。
- **文件夹式知识组织。** 用文件夹管理知识与资源。
- **Agent Memory。** 延续偏好、风格、目标与历史项目上下文，让后续协作更连贯。
- **SSO-only 模式。** 可限制仅通过企业身份提供商登录。

## 体验优化

- **新增 `ExtendParamsTypeSchema`。** 模型配置更灵活。
- **更新 Kimi K2.5 与 Qwen3 Max Thinking。** 两个模型同步刷新。

## 问题修复

- **Gemini 2.5 流式传输。** 修复流式传输行为异常。
