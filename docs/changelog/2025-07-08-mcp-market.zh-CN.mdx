# MCP 市场与搜索服务商扩展 🔍

## 新功能

- **MCP 市场。** 以往安装 MCP 插件需要手动配置，现在市场直接在桌面端提供一键安装 —— 浏览可用工具、了解功能，无需离开界面或折腾配置文件即可添加到工作区。
- **新增 Brave、Google PSE、Kagi 搜索。** 三个内置搜索服务商，可按准确度、速度或隐私需求选择。
- **Vertex AI Google Search Grounding。** 支持检索增强生成场景。
- **Amazon Cognito 与 Google SSO。** 已使用这些身份系统的团队无需额外凭证即可接入 LobeHub。
- **页面访问保护。** 可按登录状态控制内容可见范围。
- **v0 (Vercel) 服务商。** 运行时多了一个服务商选择。
- **事件追踪分析框架。** 便于洞察使用模式。

## 体验优化

- **移动端模型选择器。** 优化布局与文本溢出处理。
- **加载动画。** 切换效果更顺滑。
- **Gemini 推理参数。** 优化 `thinkingBudget` 配置与 `reasoning_effort` 参数处理。
- **搜索结果更干净。** 新增 Browserless `blockAds` 与 stealth 参数。
- **响应渲染过渡动画开关。** 过渡动画可自行开启或关闭。

## 问题修复

- **Firefox 中的 Mermaid 渲染。** 修复渲染异常问题。
- **多显示器窗口行为。** 桌面端窗口会在预期的显示器上打开。
- **主题边界情况。** 修复剩余的主题问题并优化分块加载。
