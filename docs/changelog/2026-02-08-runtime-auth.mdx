# Model Runtime & Authentication Improvements 🔧

## Features

- **Claude Opus 4.6 on Bedrock.** Bedrock supports the latest Anthropic model.
- **Better Notebook tool integration.** The server runtime integrates the Notebook tool more closely, with improved prompts.
- **End-user information on OpenAI Responses.** Responses API calls can carry end-user information when needed.
- **Custom avatars in the group chat sidebar.** Group chat participants can have their own avatars.
- **Storage limit notifications.** File uploads that exceed the storage limit now report it clearly.

## Improvements

- **Microsoft, OIDC, and Feishu sign-in hardened.** Authentication is strengthened across providers, with more reliable OIDC account linking and less Feishu SSO friction.
- **Mobile topic lists scroll vertically.** Long topic lists are usable on small screens.
- **Cleaner runtime structure.** Anthropic factory logic is extracted and Moonshot is migrated to RouterRuntime.
- **Task display.** Tasks are presented more clearly.
- **Local-system tool implementation.** The local system tool is more capable.

## Fixes

- **Microsoft authentication.** Sign-in problems with Microsoft are resolved.
- **Multimodal image rendering.** Images render correctly in multimodal replies.
- **PDF parsing in Docker.** PDFs parse correctly in Docker deployments.
- **Editor content after a send error.** Your draft is no longer lost when sending fails.
