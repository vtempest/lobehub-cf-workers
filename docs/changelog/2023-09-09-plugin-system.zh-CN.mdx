# 支持插件系统

<Video src="/blog/assets/28616219/f29475a3-f346-4196-a435-41a6373ab9e2.mp4" />

## 新功能

- **插件系统。** 助理不再局限于内置能力，社区开发的插件让它可以获取实时数据、与外部平台交互，并在对话内处理各类专业工作流。
- **实时信息获取。** 联网搜索等插件让助理突破模型知识截止日期的限制，随时查询最新资讯、技术文档、股价或天气。
- **网页搜索与文档查询。** 执行网页搜索获得最新答案，并查询技术文档与参考资料。
- **第三方平台数据。** 直接在对话中获取 Bilibili、Steam 等平台的数据。
- **对话内生成图片。** 无需切换工具，在对话过程中按需生成图片。
- **社区驱动的灵活性。** 开发者可以构建并分享自定义插件，你只需按工作流启用所需插件 —— 编程助理启用文档搜索和代码执行，创意助理使用图像生成和内容研究。同一个助理通过不同插件适应不同场景。
- **语音合成选项。** 新增 OpenAI Audio 与 Microsoft Edge Speech 高品质语音，可按个人偏好或使用场景选择声音。

了解更多插件使用方法，请查看[文档](/zh/docs/usage/plugins/basic)。
