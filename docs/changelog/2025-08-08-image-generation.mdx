# Image Generation, Desktop, and Auth Updates 🎨

## Features

- **AI image generation.** Google Imagen, Qwen, Zhipu CogView4, and MiniMax are supported, so you can pick a provider for quality, speed, or budget without changing your workflow — generate visuals in chat without switching tools, compare outputs across providers for the same prompt, and route image requests by project need.
- **Amazon Cognito, Google SSO, and Okta.** If your organization already runs on these systems, connecting LobeHub is a configuration step rather than a migration project.
- **Authentication for Streamable HTTP MCP servers.** Authenticated MCP servers are supported.
- **API Key management.** The interface is fully functional for creating, managing, and rotating keys.
- **Desktop network proxy configuration.** The app adapts to different network environments.
- **Desktop custom hotkeys, OAuth refinements, and remote chat.** Desktop workflows fit more team setups.
- **Model library updates.** Claude Opus 4.1, Grok-4, Kimi K2, and Ollama gpt-oss join the lineup, with updates to Gemini 2.5 Flash-Lite GA, Hunyuan A13B thinking, and Doubao reasoning models.

## Improvements

- **Desktop notifications.** The app can notify you outside the window.
- **Settings window layout.** The layout is refined.
- **Multi-monitor behavior.** Windows behave correctly across displays.
- **MCP plugin invocation and rendering.** Plugin calls and their output render better.

## Fixes

- **Gemini Artifacts line breaks.** Line-break handling in Artifacts is fixed.
