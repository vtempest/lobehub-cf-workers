# Custom AI Provider Management

## Features

- **Rebuilt provider management.** The system is rebuilt from the ground up, in both the open-source edition and [LobeHub Cloud](https://LobeHub.com), so you are no longer limited to a fixed set of pre-configured providers.
- **Add custom providers.** Connect to any OpenAI-compatible API endpoint.
- **Edit existing setups.** Modify provider settings without waiting for an update.
- **Configure custom models.** Define your own model entries with specific capabilities — vision, function calling, file support.
- **Remove unused providers.** Clean up the list to focus on what you actually use.
- **Multimodal ready.** Language, image, and voice capabilities are supported today; video and music generation are planned for upcoming releases.
