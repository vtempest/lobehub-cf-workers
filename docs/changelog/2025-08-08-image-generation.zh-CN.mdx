# 图像生成、桌面端与认证更新 🎨

## 新功能

- **AI 图像生成。** 支持 Google Imagen、Qwen、智谱 CogView4、MiniMax 等服务商，可按质量、速度和成本偏好选择，无需改变整体工作流 —— 直接在对话中生成视觉素材、对比不同服务商对同一提示词的输出，并按项目需求灵活路由图像请求。
- **Amazon Cognito、Google SSO 与 Okta。** 如果你的组织已在运行这些系统，接入 LobeHub 只是配置步骤而非迁移项目。
- **Streamable HTTP MCP Server 认证。** 支持需要认证的 MCP 服务器。
- **API Key 管理。** 管理界面完整支持创建、管理与轮换密钥。
- **桌面端网络代理配置。** 应用可适配不同网络环境。
- **桌面端自定义快捷键、OAuth 优化与远程聊天。** 桌面工作流适配更多团队配置。
- **模型库更新。** 新增 Claude Opus 4.1、Grok-4、Kimi K2、Ollama gpt-oss，并更新 Gemini 2.5 Flash-Lite GA、Hunyuan A13B 思维模型与 Doubao 推理模型。

## 体验优化

- **桌面端通知。** 应用可在窗口之外提醒你。
- **设置窗口布局。** 布局经过优化。
- **多显示器体验。** 窗口在多屏环境下表现正常。
- **MCP 插件调用与渲染。** 插件调用及其输出展示更完善。

## 问题修复

- **Gemini Artifacts 换行。** 修复 Artifacts 中的换行处理问题。
