# MCP Marketplace and Search Provider Expansion 🔍

## Features

- **MCP Marketplace.** Installing MCP plugins used to mean manual setup; now the marketplace brings one-click installation to the desktop app — browse available tools, see what they do, and add them to your workspace without leaving the interface or touching config files.
- **Brave, Google PSE, and Kagi search.** Three more built-in search providers, so you can pick for accuracy, speed, or privacy.
- **Vertex AI Google Search Grounding.** Grounded generation workflows are supported.
- **Amazon Cognito and Google SSO.** Teams already on these identity systems can connect LobeHub without another set of credentials.
- **Page access protection.** Control who sees what based on sign-in status.
- **v0 (Vercel) provider.** Another runtime provider option.
- **Analytics event tracking.** An event-tracking framework gives better visibility into usage patterns.

## Improvements

- **Mobile model selector.** Layout and text overflow handling are refined.
- **Loading animations.** Transitions are smoother.
- **Gemini reasoning parameters.** `thinkingBudget` configuration and `reasoning_effort` handling are optimized.
- **Cleaner search results.** Browserless `blockAds` and stealth parameters are added.
- **Response rendering animation toggle.** Transition animation can be turned on or off.

## Fixes

- **Mermaid renders in Firefox.** The rendering issue is resolved.
- **Multi-monitor window behavior.** Desktop windows open on the expected display.
- **Theme edge cases.** Remaining theme issues are fixed and chunked loading is optimized.
