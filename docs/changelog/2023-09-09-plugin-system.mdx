# Supported Plugin System

<Video src="/blog/assets/28616219/f29475a3-f346-4196-a435-41a6373ab9e2.mp4" />

## Features

- **Plugin system.** Agents are no longer limited to built-in capabilities: community-built extensions let them pull live data, interact with external platforms, and handle specialized workflows without leaving the conversation.
- **Real-time information.** Plugins such as web search let an Agent fetch current news, documentation, stock prices, or weather, instead of stopping at the underlying model's knowledge cutoff.
- **Web search and documentation lookup.** Run web searches for up-to-date answers, and query documentation sites and technical references.
- **Platform data retrieval.** Pull data from services like Bilibili or Steam directly into a conversation.
- **On-demand image generation.** Generate images during a conversation without switching tools.
- **Community-powered flexibility.** Developers can build and share custom plugins, and you enable only the ones your workflow needs — documentation search and code execution for a coding assistant, image generation and content research for a creative one. The same Agent adapts to different contexts through its enabled plugins.
- **Voice synthesis options.** Quality voices from OpenAI Audio and Microsoft Edge Speech let you pick one that matches your preference or scenario.

Learn more about plugin usage in our [documentation](/en/docs/usage/plugins/basic).
