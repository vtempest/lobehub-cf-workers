# DeepSeek R1 集成与思维链透明化

## 新功能

- **支持 DeepSeek R1。** v1.49.12 已在社区版与 Cloud 版完整接入该模型。
- **思维链完整呈现。** 模型处理问题时，你能实时看到推理过程，而不只是收到最终答案。
- **问题求解更具协作感。** 调试脚本、解数学题或分析复杂话题时，你可以看到模型的逻辑在哪些环节与你的意图一致、哪些地方需要补充说明；推理展示自然融入对话流程，不会干扰界面阅读。
- **如何开始。** 升级至 v1.49.12 或访问 [LobeHub.com](https://LobeHub.com)，在模型下拉菜单中选取 DeepSeek R1 并开始对话。

## 体验优化

- **思维链渲染更快。** 长推理序列的渲染性能得到优化。

## 问题修复

- **推理展示保持一致。** 修复推理内容解析问题，在不同响应类型中展示效果一致。
