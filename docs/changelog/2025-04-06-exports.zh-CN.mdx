# 快捷键自定义、数据导出与服务商扩展

## 新功能

- **快捷键自定义。** 把常用操作映射到自己顺手的按键，不必去适应预设键位布局。
- **新增清除与删除快捷键。** 清除对话和删除消息都有了快捷键，键盘驱动的会话更少需要伸手够鼠标。
- **PgLite 与 PostgreSQL 数据导出。** 备份对话记录或在不同安装环境之间迁移数据，无需手动操作数据库 —— 适合归档重要对话历史、迁移到新设备或服务器，以及在云端存储之外保留本地备份。
- **六个新服务商。** Xinference、Cohere、Search1API、Infini-AI、PPIO 加入现有的服务商选择流程，无需额外配置。
- **推理内容专用选择器。** Claude 3.7 与 DeepSeek R1 的思维链展示得到优化，长对话中的推理内容更易阅读和定位。
- **网页爬取能力增强。** 特别支持 YouTube、Reddit 与微信公众号链接，优化短内容提取，并由 Search1API 提供额外的爬虫实现以扩大覆盖。
- **模型库更新。** Google Gemini 2.5 Pro Experimental 与 Gemini 2.0 Flash 系列、Anthropic 上下文缓存支持、OpenAI gpt-4o-mini-tts、DeepSeek-V3-0324、Hunyuan-T1-Latest、QwQ、QVQ-Max，以及百度文心 ernie-x1-32k-preview。

## 体验优化

- **界面改进。** 重构 Drawer 样式、优化编辑器滚动、支持截图分享至剪贴板。
- **搜索增强。** 在线搜索支持非函数调用模型（包括 DeepSeek R1），并为文心和混元增加内置网页搜索。
- **文件处理。** 新增 EPUB 分块支持，优化 PDF 处理。
- **性能提升。** 重构 Agent Runtime，优化数据库核心代码。

## 问题修复

- **LiteLLM 流式统计。** 修复流式统计数据不准确的问题。
- **主题闪烁。** 加载时不再出现主题闪烁。
- **知识库行为异常。** 解决多个知识库相关问题。
- **微信登录。** 修复微信登录失败问题。
