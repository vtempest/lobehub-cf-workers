# 知识库：管理与对话文件的新方式

## 新功能

- **知识库上线，开源版与 Cloud 版同步提供。** 文件管理、智能处理与文件对话整合到同一流程，开源版与 Cloud 版（LobeHub.com）同时可用。
- **文件专属空间。** 左侧边栏新增 **「文件」** 一级入口，上传内容有了固定归宿，不再散落在各处。
- **全类型文件统一存放。** 支持上传文档、图片、音频、视频等多种类型。
- **内置在线预览。** PDF、Excel、Word、PPT、TXT 等常见格式可直接预览，预览组件基于开源方案构建，为扩展更多格式留出空间。
- **无限数量的知识库。** 按场景自由创建，个人资料沉淀与团队主题整理都能覆盖。
- **自动分块与向量化。** 文件上传后自动处理，并支持片段级预览，帮助更快定位内容。
- **集成 Portal 交互范式。** 更高效地预览与检索文件信息。
- **为多媒体处理预留空间。** 架构上已为音频、图片、视频的智能处理做好准备。
- **对话框内直接上传。** 上传流程直观，过程中进度反馈清晰。

所有功能均已在 [GitHub 仓库](https://github.com/lobehub/lobe-chat) 开源，欢迎访问 [LobeHub Cloud](http://LobeHub.com) 体验完整功能。
