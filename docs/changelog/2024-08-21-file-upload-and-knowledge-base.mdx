# Knowledge Base: A New Way to Manage and Chat with Your Files

## Features

- **Knowledge base, open-source and Cloud.** File management, intelligent processing, and file-based dialogue come together in one workflow, live in both the open-source edition and Cloud (LobeHub.com).
- **A dedicated Files space.** A **Files** entry in the left sidebar gives uploaded content a permanent home instead of scattering it across entry points.
- **All file types stored in one place.** Upload documents, images, audio, and video.
- **Built-in online preview.** PDF, Excel, Word, PPT, and TXT preview inside the product, on an open-source foundation designed to expand to more formats over time.
- **Unlimited knowledge bases.** Create as many as your scenarios need, from personal reference collections to domain-focused team libraries.
- **Automatic chunking and vectorization.** Files are processed on upload, with fragment preview for faster inspection.
- **Portal integration.** The Portal interaction pattern supports quicker preview and retrieval of file content.
- **Room for multimedia processing.** The architecture reserves space for planned intelligent processing of audio, images, and video.
- **Upload from the dialogue box.** Files go up directly inside the conversation, with clear progress feedback during the upload.

All features are open-sourced on the [GitHub repository](https://github.com/lobehub/lobe-chat). Visit [LobeHub Cloud](http://LobeHub.com) to experience the full functionality.
