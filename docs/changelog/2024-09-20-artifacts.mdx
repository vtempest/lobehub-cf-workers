# LobeHub v1.19: Artifacts, Discovery, and More Models

## Features

- **Artifacts.** LobeHub replicates the core Claude Artifacts experience, so you can generate and interact with rich content directly in the conversation.
- **SVG graphics.** Generate and display vector graphics that render in real time.
- **HTML pages.** Create and preview interactive web pages without leaving the chat.
- **Rich documents.** Produce formatted documents in multiple output formats.
- **Python code execution (coming).** Still in development and planned for a future release; once available it can be combined with OpenAI Code Interpreter.

![Artifacts Feature Showcase](/blog/assets/b2845057b23bccfec3bfea90e43ac381.webp)

- **Redesigned discovery page.** Richer content categories — AI Assistant Marketplace, Plugin Showcase, Model List, and Provider Introductions — raise information density while making capabilities easier to browse. Knowledge base sharing, Artifacts showcases, and curated conversation sharing are planned next.
- **GitHub Models provider.** Contributed by [@CloudPassenger](https://github.com/CloudPassenger): prepare a GitHub Personal Access Token (PAT), configure the provider in settings, and start using the free models available on GitHub Models. This significantly expands the available model pool.

## Improvements

- **Full Artifacts support.** SVG, HTML, and document generation all ship together.
- **Discovery page rebuilt.** Marketplace, plugins, models, and providers share one redesigned surface.
- **GitHub Models added as a provider.** More models are available for different conversation scenarios.
- **Python code execution prepared.** The feature is queued for an upcoming release.
- **Discovery page expansion planned.** Knowledge base and Artifacts sharing are next on the roadmap.
