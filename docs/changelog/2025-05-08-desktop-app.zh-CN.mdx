# Lobe UI v2 设计系统与桌面端正式发布

## 新功能

- **Lobe UI v2 设计系统。** 每个组件都经过重新审视，追求清晰与一致，按钮、排版、间距与色调在整个应用中保持统一 —— 视觉干扰更少，交互更可预测。
- **界面细节更清爽。** 侧边栏更简洁，模型标签排列更整齐，系统角色可折叠以节省空间，移动端布局针对拇指操作做了优化。
- **Windows 与 macOS 桌面端。** 原生应用带来系统托盘集成、原生窗口控制与操作系统级快捷键 —— 适合不想保持浏览器标签页打开、偏好原生窗口管理与 Alt-Tab 切换、需要系统级快捷键，或希望应用固定在 Dock 栏的多工作区场景。
- **支持 Streamable HTTP MCP 服务器。** MCP 协议支持扩展至 Streamable HTTP。
- **Stdio MCP 安装更流畅。** 支持环境变量参数，服务器配置更灵活。
- **新增 Search1API 搜索服务商。** 搜索服务商列表多了一个选择。
- **SearXNG 支持分类与时间范围。** 可按分类或时间窗口筛选结果。
- **Keycloak SSO。** SSO 集成扩展至 Keycloak，OIDC OAuth 工作流优化后摩擦点更少。
- **模型库更新。** OpenAI GPT-4.1 系列与 o3/o4-mini；Google Gemini 2.5 Pro Experimental，支持推理 Token 追踪；xAI Grok 3 系列；Anthropic、Mistral、Qwen、Ollama 最新模型刷新。

## 体验优化

- **性能统计。** Token 生成吞吐率显示、阿里云百炼 Token 追踪、Google Gemini 推理 Token 统计。
- **快捷键增强。** 新增清除聊天与删除消息快捷键，并支持完整的自定义快捷键配置。
- **工具调用。** 支持更新工具调用参数并重新触发，本地文件插件新增写入文件能力。
- **错误处理。** 出错时支持复制和编辑。
- **网页爬取。** 新增小红书爬虫规则。
