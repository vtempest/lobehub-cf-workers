# LobeHub 1.0: A New Foundation for Persistent, Multi-User Workspaces

## Features

- **Server-side database.** Conversations and Agents now live beyond a single browser session, so you can switch from laptop to desktop without losing context and build up knowledge over time instead of starting from zero. The 0.x era ran on browser storage — fast and simple, but with no sync, no knowledge bases, and no team sharing.
- **Knowledge bases.** Store documents and reference them across conversations.
- **Cross-device sync.** Pick up exactly where you left off on any device.
- **Private Agent marketplaces.** Share specialized Agents within your team.
- **Conversation history.** Search and revisit past discussions.
- **User authentication and management.** Both next-auth and Clerk are supported as authentication providers, so multiple users can share a LobeHub instance with proper access boundaries.
- **Dedicated user panel.** Settings are restructured into one panel that brings identity, preferences, and access control together — manage account settings and API keys in one place, configure your authentication provider, control workspace access for team members, and switch between personal and team contexts.
- **LobeHub Cloud beta.** A hosted offering built on the 1.0 architecture, with server-side persistence, user management, and knowledge bases available without any setup. Daily access is limited during beta — [join the waitlist here](https://lobehub.com).

## Improvements

- **Core storage moved to PostgreSQL.** The storage layer is migrated off localStorage.
- **Database migration system.** Upgrades apply schema changes seamlessly.
- **Secure session management.** Sessions are handled with secure token handling.
- **Settings refactored into the user panel.** Account, preference, and access settings share one surface.
- **Multiple authentication providers.** The auth layer supports more than one provider.
- **Faster first load.** Server-side rendering improves initial load performance.
