# LobeHub v2.0 🎉

## Features

- **Multi-agent group chat.** Instead of asking one Agent to handle every step, run multiple specialized Agents in one conversation and have them work around the same goal.
- **Agent Builder.** Describe your goal in plain language and generate an Agent with tools, behaviors, skills, and personality in one flow.
- **Publish, remix, and adopt Agents.** Publish to the marketplace, remix community templates, or adopt an Agent directly into your Workspace and keep iterating.
- **Pages for documents.** Write and organize documents inside the knowledge workflow.
- **Folder-based knowledge organization.** Manage resources in folders.
- **Agent Memory.** Carry preferences, style, goals, and prior project context forward between sessions.
- **SSO-only mode.** Restrict sign-in to your identity provider.

## Improvements

- **`ExtendParamsTypeSchema` added.** Model configuration is more flexible.
- **Kimi K2.5 and Qwen3 Max Thinking updated.** Both models are refreshed.

## Fixes

- **Gemini 2.5 streaming.** Streaming behavior is corrected.
