# 灵活适配的认证体系：Clerk 与 Next-Auth 双方案支持

## 新功能

- **双认证方案。** LobeHub 同时集成 next-auth 与 Clerk，你可以先用社交登录快速上线，待业务需要时再升级安全能力，无需重构整个认证架构。
- **Next-Auth：快速启动。** 轻量级认证层覆盖核心能力 —— 主流 OAuth 提供商、邮箱登录、凭证登录，无需管理独立用户服务。
- **社交登录快速接入。** 几分钟内接入 GitHub、Google 等提供商。
- **开箱即用的会话管理。** 会话由框架处理，登录界面与流程仍由你完全掌控。
- **隐私友好。** 用户数据保留在自有基础设施中。
- **Clerk：企业级身份管理。** 托管身份平台提供的能力不止于登录，并随产品规模自动扩展。
- **多因素认证。** 为敏感账户提供 MFA，满足合规要求。
- **内置用户资料与账户管理。** 开箱即用的用户资料与账户管理界面。
- **登录行为监控。** 实时监控登录活动。
- **免运维的身份基础设施。** 高扩展性，随用量增长而无需自行运维。

## 体验优化

- **支持 next-auth v5 beta。** 新版本上的会话处理机制得到改进。
- **OAuth 错误提示更清晰。** OAuth 连接失败时会说明具体原因。

## 问题修复

- **自定义登录页不再循环跳转。** 修复自定义登录页面导致的重定向循环问题。
