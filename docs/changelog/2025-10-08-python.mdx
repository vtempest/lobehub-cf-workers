# Claude Sonnet 4.5 and Built-in Python Plugin 🐍

## Features

- **Built-in Python plugin.** Execute Python without leaving the conversation — run calculations, transform data, or test snippets and see results next to the discussion, with no separate notebook or terminal to switch to.
- **Chat list minimap.** A condensed view of a long conversation lets you jump to a specific section instead of scrolling endlessly.
- **Richer text editing.** The rich text editor supports math formulas, task lists, and parallel sending, making structured messages with mixed content easier to draft.
- **Qwen image editing.** Edit images through Qwen models directly in the chat interface.
- **Claude Sonnet 4.5.** Anthropic's latest reasoning capabilities are available in LobeHub.
- **New providers and models.** Vercel AI Gateway joins as a provider, alongside Seedream 4.0, CometAPI, and NewAPI, and Gemini 2.5 video understanding is updated.

## Improvements

- **Resizable chat input.** Drafting longer messages is more comfortable.
- **Mobile title display.** Titles read better on small screens.
- **Base64 image syntax.** Inline Base64 images are supported.

## Fixes

- **`.doc` file parsing.** Parsing legacy Word documents is more reliable.
