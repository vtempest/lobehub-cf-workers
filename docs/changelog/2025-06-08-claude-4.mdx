# Prompt Variables and Claude 4 Reasoning Model Support

## Features

- **Prompt variables.** Placeholder variables work in prompts and the input box, so one prompt structure can be reused with different dynamic values instead of being edited by hand each time. Variables use simple syntax and are filled in at runtime.
- **Where variables help.** Templates that need a name, date, or topic inserted; structured analysis where only the source material changes; and repeated workflows with consistent formatting but variable content.
- **Claude 4 reasoning models.** Anthropic Claude 4 is fully integrated, including Web Search tool support and Beta Header compatibility, so you can run complex reasoning with transparent chain-of-thought, combine reasoning with live web retrieval in one conversation, and pick up new Claude capabilities as they land.
- **ModelScope provider.** Another provider joins the lineup without changing how you work.
- **Wider search and crawling coverage.** Support is extended across more platforms for better content coverage.
- **File uploads in chat context.** Reference documents and spreadsheets inside an ongoing conversation, with improved PDF and XLSX parsing.
- **Protected page access.** Sensitive workflows can be gated behind sign-in.

## Improvements

- **PDF and XLSX extraction accuracy.** Content extraction is more reliable.
- **File upload handling in chat.** Uploads behave more predictably inside a conversation.
- **Route protection for authenticated pages.** Clerk middleware handles authentication edge cases more reliably.
- **Claude 4 token handling.** Provider-specific optimizations keep token accounting correct.
