# OpenAI O1 系列模型现已可用

## 新功能

- **支持 OpenAI O1 系列模型。** v1.17.0 完整支持新发布的 O1 系列，社区版用户与 [Cloud 版本](https://LobeHub.com) 订阅用户同步开放，无需额外配置。
- **OpenAI o1-preview。** 完整推理能力，适合复杂任务。
- **OpenAI o1-mini。** 更快、更经济，适合日常工作。
- **结构化推理能力更强。** O1 系列擅长产出一次就能编译运行的正确代码、带讲解的逐步数学推导，以及多步骤指令的精准执行。
- **模型选择器中直接可选。** 所有用户都能在模型选择器中找到这两款模型；Cloud 订阅用户即刻可用，自部署用户更新至 v1.17.0 后即可访问。

通过这次发布，LobeHub 继续紧跟最新模型生态。期待 O1 系列帮助你在实际工作中探索更多可能。
