# 支持导出对话为 Markdown 或 OpenAI JSON 格式

## 新功能

- **Markdown 导出。** v1.28.0 把对话转为整洁可读的文档，可直接导入笔记、知识库或报告，无需手动复制粘贴与排版。

![将对话导出为 Markdown 格式文本](/blog/assets/29b13dc042e3b839ad8865354afe2fac.webp)

- **OpenAI 格式 JSON 导出。** 导出遵循 OpenAI messages 规范，可直接用于 API 调试工具，或作为结构化训练数据用于模型微调。
- **保留 Tool Calling 数据。** 工具调用保持原始结构，便于分析和改进 Agent 调用外部工具的行为。

![将对话导出为 OpenAI 接口规范的 JSON](/blog/assets/5bbb4b421d6df63780b3c7a05f5a102d.webp)

## 体验优化

- **新增 Markdown 导出选项。** 对话分享多了一种文档友好的格式。
- **新增 OpenAI 格式 JSON 导出。** 保留完整消息结构。
- **导出时保留 Tool Calling 原始数据。** 工具调用内容不会被压平。
