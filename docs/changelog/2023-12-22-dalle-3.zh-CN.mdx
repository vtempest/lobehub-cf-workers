# 支持 Text to Image 文生图

## 新功能

- **对话内文生图。** 助理可直接调用 [`DALL-E 3`](https://openai.com/dall-e-3)、[`MidJourney`](https://www.midjourney.com/) 与 [`Pollinations`](https://pollinations.ai/)，在同一段对话中把描述变成图像。
- **无需切换工具。** 以往生成 AI 图像要离开对话、打开另一个工具、编写提示词、等待结果再复制回来；现在只需描述想要什么，图片就出现在对话里。
- **快速迭代。** 要求调整、探索变体、优化描述都不必切换上下文，对话历史会保留创作方向，方便引用此前的想法继续发展。
- **私密且完整的创作过程。** 提示词、迭代过程与最终图像都留在现有对话中，无需管理多个账号或在平台之间跳转。
- **多种生成选项。** DALL-E 3 渲染精细准确，MidJourney 富有艺术感与氛围感，Pollinations 生成快速便捷，助理可帮你为每个任务选择合适的工具。
