# 模型运行时与认证改进 🔧

## 新功能

- **Bedrock 支持 Claude Opus 4.6。** Bedrock 已接入 Anthropic 最新模型。
- **Notebook 工具接入更完善。** 服务端运行时进一步整合 Notebook 工具，并优化了提示词。
- **OpenAI Responses 支持终端用户信息。** Responses API 请求可按需携带终端用户信息。
- **群聊侧边栏自定义头像。** 群聊参与者可使用各自的头像。
- **存储限制通知。** 文件上传超出存储限制时会明确提示。

## 体验优化

- **Microsoft、OIDC 与飞书登录加固。** 认证链路集中加固，OIDC 账户关联更稳定，飞书 SSO 登录摩擦进一步降低。
- **移动端话题列表支持垂直滚动。** 小屏幕上的长列表可正常浏览。
- **运行时结构更清晰。** 提取 Anthropic 工厂逻辑，并将 Moonshot 迁移到 RouterRuntime。
- **任务展示。** 任务信息呈现更清晰。
- **本地系统工具实现。** 本地系统工具能力增强。

## 问题修复

- **Microsoft 登录。** 修复 Microsoft 登录失败问题。
- **多模态图片渲染。** 多模态回复中的图片可正常渲染。
- **Docker 环境下的 PDF 解析。** Docker 部署中 PDF 可正常解析。
- **发送失败后编辑器内容丢失。** 发送失败时草稿不再丢失。
