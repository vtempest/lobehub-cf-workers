# LobeHub v1.19：Artifacts、发现页与更多模型

## 新功能

- **Artifacts。** LobeHub 已还原 Claude Artifacts 的核心体验，可在对话中直接生成并交互丰富内容。
- **SVG 图形。** 生成并展示实时渲染的矢量图形。
- **HTML 页面。** 创建并预览交互式网页，无需离开对话。
- **富文档。** 以多种输出格式生成格式化文档。
- **Python 代码执行（即将上线）。** 功能已完成开发，计划在后续版本上线，届时可与 OpenAI Code Interpreter 结合使用。

![Artifacts 功能展示](/blog/assets/8d6c17a6ea5e784edf4449fb18ca3f76.webp)

- **发现页重新设计。** 更丰富的内容分类 —— AI 助手市场、插件展示、模型列表、服务商介绍 —— 在提升信息密度的同时让能力浏览更直观。知识库分享、Artifacts 展示与精选对话分享将陆续加入。
- **GitHub Models 服务商。** 由社区成员 [@CloudPassenger](https://github.com/CloudPassenger) 贡献：准备 GitHub Personal Access Token (PAT)，在设置中配置服务商信息，即可使用 GitHub Models 上的免费模型，可选模型范围显著扩展。

## 体验优化

- **完整支持 Artifacts。** SVG、HTML 与文档生成一并上线。
- **发现页重构。** 市场、插件、模型与服务商整合在同一界面。
- **新增 GitHub Models 服务商。** 不同对话场景有了更多模型选择。
- **Python 代码执行已就绪。** 功能开发完成，待后续版本上线。
- **发现页扩展计划。** 知识库与 Artifacts 分享已在规划中。
