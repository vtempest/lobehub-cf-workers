# 本地模型与云端 AI 并行使用

## 新功能

- **v0.127.0 支持 Ollama。** 用与云端模型一致的对话体验运行本地大语言模型，无需学习新界面，也不会割裂工作流程。
- **一行命令接入。** 如果你已运行 Ollama，只需一条 Docker 命令即可连接：

```bash
docker run -d -p 3210:3210 -e OLLAMA_PROXY_URL=http://host.docker.internal:11434/v1 lobehub/lobe-chat
```

- **本地模型出现在同一处切换。** LobeHub 会自动检测本地模型，并与 GPT-4、Claude 等一同列出，可在同一工作区自由混用云端与本地模型。
- **隐私优先。** 敏感对话全程留在本地机器。
- **成本控制。** 实验性使用无需按 token 付费。
- **离线使用。** 无网络连接时仍可继续工作。
- **模型测试。** 生产部署前先评估开源模型效果。

## 体验优化

- **自动模型发现。** 无需手动配置即可从 Ollama 端点发现模型。
- **连接错误提示更清晰。** Ollama 服务不可达时的错误处理得到优化。

## 问题修复

- **本地模型流式输出正常。** 修复本地模型兼容性的流式响应处理问题。
