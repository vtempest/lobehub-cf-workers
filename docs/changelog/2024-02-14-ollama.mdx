# Run Local Models Alongside Cloud AIs

## Features

- **Ollama support in v0.127.0.** Run local large language models with the same chat experience you use for cloud providers — no separate interface to learn and no fragmented workflow.
- **Connect in one command.** If Ollama is already running, point LobeHub at it with a single Docker command:

```bash
docker run -d -p 3210:3210 -e OLLAMA_PROXY_URL=http://host.docker.internal:11434/v1 lobehub/lobe-chat
```

- **Local models in the same switcher.** LobeHub detects your local models and lists them alongside GPT-4, Claude, and the rest, so you can mix cloud and local models in one workspace.
- **Privacy-first work.** Keep sensitive conversations on your own machine.
- **Cost control.** Experiment without per-token charges.
- **Offline access.** Keep working without an internet connection.
- **Model testing.** Evaluate open-source models before deploying them to production.

## Improvements

- **Automatic model discovery.** Models are discovered from Ollama endpoints without manual configuration.
- **Clearer connection errors.** Error handling is improved when the Ollama service is unreachable.

## Fixes

- **Streaming works with local models.** Streaming response handling is fixed for local model compatibility.
