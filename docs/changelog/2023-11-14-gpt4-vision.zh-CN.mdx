# 支持模型视觉识别

## 新功能

- **模型视觉识别。** 对话不再局限于纯文字，现已支持 OpenAI [`gpt-4-vision`](https://platform.openai.com/docs/guides/vision)、Google Gemini Pro Vision 以及智谱 GLM-4 Vision。
- **上传或拖拽图片。** 把截图、照片、图表或任意视觉参考拖入对话框，助理即可结合上下文理解其内容。
- **日常与专业场景兼顾。** 分享生活照片展开讨论、上传界面截图获取设计反馈、请助理解读图表，或直接引用视觉内容而无需用文字描述。
- **上下文感知的视觉理解。** 助理不只是「看见」图片，而是在持续对话中理解它 —— 你可以针对细节追问、比较多张图片，或把视觉资料作为复杂讨论的参考。
- **专业领域上下文更清晰。** 医学影像讨论、建筑方案评审、技术图表分析，当双方看到同一份视觉参考时交流更高效。
- **个性化语音交互。** 新增 OpenAI Audio 与 Microsoft Edge Speech 高品质语音，可选择符合你风格或场景的声音。
