# Claude Sonnet 4.5 与内置 Python 插件 🐍

## 新功能

- **内置 Python 插件。** 无需离开对话即可执行代码 —— 进行计算、转换数据或测试代码片段，结果立即在讨论旁展示，不必切换到独立的笔记本或终端。
- **聊天列表小地图。** 长会话的浓缩视图让你直接跳转到特定段落，无需无尽滚动。
- **更丰富的文本编辑。** 富文本编辑器支持数学公式、任务列表与并行发送，混合内容的结构化消息更易起草。
- **Qwen 图像编辑。** 可直接在聊天界面通过 Qwen 模型编辑图像。
- **Claude Sonnet 4.5。** Anthropic 最新的推理能力已引入 LobeHub。
- **新增服务商与模型。** Vercel AI Gateway 加入服务商阵容，同时新增 Seedream 4.0、CometAPI、NewAPI，Gemini 2.5 视频理解能力同步更新。

## 体验优化

- **聊天输入框可调整大小。** 起草长消息更舒适。
- **移动端标题显示。** 小屏幕上的标题更易读。
- **支持 Base64 图像语法。** 可直接内联 Base64 图像。

## 问题修复

- **`.doc` 文件解析。** 旧版 Word 文档解析更稳定。
