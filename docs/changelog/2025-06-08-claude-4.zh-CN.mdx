# 提示词变量与 Claude 4 推理模型支持

## 新功能

- **提示词变量。** 提示词和输入框中可以使用占位符变量，同一套结构搭配不同动态值重复使用，无需每次手动编辑。变量使用简单语法定义，在运行时填充。
- **变量的适用场景。** 每次需要插入姓名、日期或主题的模板；仅源材料变化、格式固定的结构化分析；格式一致但内容可变的高频工作流。
- **Claude 4 推理模型。** Anthropic Claude 4 已完整集成，包含 Web Search 工具支持与 Beta Header 兼容性，可执行具备透明思维链的复杂推理、在单次对话中结合推理与实时网页检索，并在新能力发布时立即使用。
- **新增 ModelScope 服务商。** 可用模型范围进一步扩展，且不改变你的工作方式。
- **搜索与爬虫覆盖更广。** 支持已扩展到更多平台，内容覆盖更完整。
- **聊天上下文内上传文件。** 可在持续对话中引用文档与电子表格，PDF、XLSX 解析同步改进。
- **受保护的页面访问。** 敏感工作流可按登录状态限制访问。

## 体验优化

- **PDF 与 XLSX 提取更准确。** 内容提取的准确性提升。
- **聊天中的文件上传处理。** 对话内上传行为更稳定。
- **认证页面路由保护。** Clerk 中间件更可靠地处理认证边界情况。
- **Claude 4 Token 处理。** 服务商特定优化保证 Token 统计准确。
