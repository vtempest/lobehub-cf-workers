# Lobe UI v2 Design System and Desktop App Launch

## Features

- **Lobe UI v2 design system.** Every component has been reconsidered for clarity and consistency, so buttons, typography, spacing, and color align across the whole application — less visual noise and more predictable interactions.
- **Cleaner interface details.** The sidebar is cleaner, model tags are arranged more neatly, system roles can be collapsed to save space, and mobile layouts are refined for thumb reachability.
- **Desktop app for Windows and macOS.** A native application with system tray integration, native window controls, and OS-level keyboard shortcuts — useful when you want LobeHub without a browser tab open, prefer native window management and alt-tabbing, need system-level shortcuts, or work across multiple workspaces with the app docked consistently.
- **Streamable HTTP MCP servers.** MCP protocol support is extended to Streamable HTTP.
- **Smoother Stdio MCP installation.** Environment variable parameters are supported for more flexible server configurations.
- **Search1API as a search provider.** A new option in the search provider list.
- **SearXNG category and time-range selection.** Narrow results to a category or a time window.
- **Keycloak SSO.** SSO integration expands to Keycloak, and the OIDC OAuth workflow is refined for fewer friction points.
- **Model library updates.** OpenAI GPT-4.1 series and o3/o4-mini; Google Gemini 2.5 Pro Experimental with reasoning token tracking; xAI Grok 3 series; and latest refreshes for Anthropic, Mistral, Qwen, and Ollama.

## Improvements

- **Performance stats.** Token generation throughput display, Aliyun Bailian token tracking, and Google Gemini reasoning token statistics.
- **Hotkey enhancements.** Shortcuts for clearing chat and deleting messages, plus full custom hotkey configuration.
- **Tool calling.** Tool-call arguments can be updated and re-triggered, and local file plugins can write files.
- **Error handling.** Copy and edit options are available when an error occurs.
- **Web crawling.** Crawler rules for Xiaohongshu are added.
