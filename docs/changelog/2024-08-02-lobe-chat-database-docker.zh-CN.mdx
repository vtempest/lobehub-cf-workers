# LobeHub Database Docker 镜像：云端部署的最后一块拼图

## 新功能

- **官方数据库 Docker 镜像。** v1.8.0 补齐了服务端部署链路，团队可以顺畅完成完整的云端部署流程。
- **内置 Postgres 与 NextAuth 预配置。** 云端数据同步与灵活认证开箱即用，并支持 Auth0 等第三方 SSO 服务商集成。
- **轻量而完整。** 镜像仅 90MB，却提供完整的数据库环境；预置 Server Postgres 与 NextAuth 鉴权体系，从第一刻起保证稳定连通。
- **部署后即可同步。** 客户端与服务端的数据流转无需额外配置。
- **自部署文档重构。** 部署文档按框架思路前置说明、详细部署案例指引、完整自部署操作指南重新梳理。访问[官方文档](https://lobehub.com/zh/docs/self-hosting/server-database)开始部署你自己的 LobeHub 服务。

## 体验优化

- **发布 90MB 官方数据库镜像。** 镜像已正式上架，可直接拉取。
- **预置 Server Postgres 与 NextAuth 认证体系。** 首次启动无需手动配置。
- **部署完成后启用云端数据同步。** 服务就绪即可同步。
- **支持 Auth0 及第三方 SSO 服务商。** 可接入更多身份提供商。
- **重构自部署文档。** 在指南之外补充了案例说明。
