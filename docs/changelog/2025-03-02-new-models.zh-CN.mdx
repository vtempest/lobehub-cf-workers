# AI 生态扩展：新增 50+ 模型与 10+ 服务商

## 新功能

- **新增 10+ 服务商。** 覆盖全球与国内主流平台，可直接从现有 LobeHub 设置中连接，无需额外配置。
- **完整支持 DeepSeek R1。** 跨服务商场景下解析表现一致，推理内容在哪里运行都一样易读。
- **推理模型覆盖扩展。** Claude 3.7 Sonnet 与 OpenAI o3-mini 会实时展示思维链，便于跟进结论的推导过程。
- **搜索能力重构。** 集成 SearchXNG 与 Perplexity 并支持深度网页爬取，可在对话中直接通过实时网页结果研究主题、对比不同服务商处理同一查询的方式，并获取更深度的内容提取。
- **Gemini 2.0 与 Qwen 原生搜索。** 这些模型现可在推理过程中直接使用搜索能力。
- **刷新 50+ 模型配置。** OpenAI gpt-4.5-preview；Anthropic Claude 3.7 Sonnet、Haiku 3.5；Google Gemini 2.0 系列优化；月之暗面、通义千问、MiniMax 最新模型；以及 Perplexity、Cloudflare、硅基流动等刷新。

## 体验优化

- **搜索结果更易读。** 优化了结果的展示格式。
- **模型参数保持同步。** 增强跨服务商的参数同步能力。

## 问题修复

- **推理展示保持一致。** 修复跨服务商的推理展示不一致问题。
