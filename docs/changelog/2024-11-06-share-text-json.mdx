# Export Conversations as Markdown or OpenAI JSON

## Features

- **Markdown export.** v1.28.0 turns conversations into clean, readable documents you can move straight into notes, wikis, or reports — no copy-pasting or manual cleanup.

![Exporting Conversations as Markdown Text](/blog/assets/29b13dc042e3b839ad8865354afe2fac.webp)

- **OpenAI-format JSON export.** Exports follow the OpenAI messages format, so a conversation drops directly into API debugging tools or serves as structured training data for fine-tuning.
- **Tool calling data preserved.** Tool calls keep their original structure, which helps when analyzing or improving how Agents use external tools.

![Exporting Conversations as JSON in OpenAI API Specification](/blog/assets/5bbb4b421d6df63780b3c7a05f5a102d.webp)

## Improvements

- **Markdown export option added.** Conversation sharing gains a document-friendly format.
- **OpenAI-format JSON export added.** The full message structure is included.
- **Original tool calling format kept on export.** Tool call payloads are not flattened.
