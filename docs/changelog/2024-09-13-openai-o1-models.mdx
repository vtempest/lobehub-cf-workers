# OpenAI O1 Series Models Now Available

## Features

- **OpenAI O1 series support.** v1.17.0 adds the newly launched O1 models for both community edition users and [Cloud version](https://LobeHub.com) subscribers, with no extra configuration needed.
- **OpenAI o1-preview.** Full reasoning capabilities for complex tasks.
- **OpenAI o1-mini.** A faster, cost-effective option for everyday work.
- **Stronger structured reasoning.** The O1 series is built for code that compiles and runs correctly the first time, step-by-step mathematical derivations with explanations, and precise execution of multi-step instructions.
- **Available in the model selector.** Both models show up for all LobeHub users — Cloud subscribers can use them immediately, and self-hosted users get them after updating to v1.17.0.

With this release, LobeHub continues to track the latest model ecosystem. We look forward to seeing what you build with the O1 series.
