# Branch Conversations from Any Message

## Features

- **Branch from any message.** Conversations rarely stay linear — follow a tangent, test a different approach, or split a thread for a different audience without losing the original flow.
- **Continuation mode.** Keep the full conversation history and continue from that point, useful for exploring "what if" scenarios with context preserved.
- **Standalone mode.** Start fresh from the selected message, good for extracting a clean sub-conversation or preparing a focused excerpt to share.
- **Original conversation stays intact.** Click the branch button on a message to start a new thread; the source conversation is untouched.
- **Switch branches from the topic sidebar.** Compare outcomes and continue whichever path proves most useful.
