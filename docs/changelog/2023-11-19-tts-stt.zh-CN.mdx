# 支持 TTS & STT 语音会话

## 新功能

- **文字转语音（TTS）。** 助理可以用清晰自然的声音朗读回复。
- **语音转文字（STT）。** 用语音输入代替打字。
- **免提交互。** TTS 与 STT 结合，适合处理其他事务、通勤途中或单纯更喜欢说话的场景 —— 也更适合听觉型学习者、远离键盘的用户，以及觉得语音比文字更便捷的人。
- **每个助理独立配音。** 不同助理可以配备不同声音：专业助理使用沉稳从容的语调，创意型助理则更富表现力。
- **精选语音库。** 收录 OpenAI Audio 与 Microsoft Edge Speech 的高品质声音，覆盖不同地区与偏好。
- **完整的交流闭环。** 自然地说话、听到语音回复，并像真实对话一样保持上下文；插件、多模态支持与上下文管理都能与语音模式无缝协作。
