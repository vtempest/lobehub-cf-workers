# 个人数据统计与活跃度分享

## 新功能

- **个人数据统计页。** 清楚掌握自己的使用模式，从 Agent 使用到消息量一目了然。
- **概览数据。** 创建的助理数、发起的话题数、发送的消息数、累计生成字数。
- **排行榜。** 你最常用的模型、偏好的助理、内容最多的话题。
- **活跃度热力图。** 过去一年使用情况的视觉时间线，可以直观看到使用习惯的变化。
- **可分享的活跃度卡片。** 生成汇总数据的个人图片，发布到社交媒体或与队友对比 AI 工作流。
- **支持 PgLite 与数据库部署模式。** 打开账户菜单进入**数据统计**，面板将自动加载。
