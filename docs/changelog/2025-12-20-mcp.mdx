# MCP Cloud Endpoints and Model Library Expansion 🔌

## Features

- **Managed MCP cloud endpoints.** Marketplace integrations are supported, so you no longer need to self-host every tool — connect to managed endpoints directly from the marketplace and expand your tool set from one place.
- **New AI providers.** **ZenMux**, **Nano Banana Pro**, and **Qiniu Cloud** give teams more options when routing requests or evaluating models.
- **Pages in the knowledge base.** Organize information hierarchically instead of relying on a flat file structure.
- **Better file management and RAG search.** Day-to-day lookup is more reliable.
- **Refined OIDC and desktop login.** The authentication flow and desktop sign-in experience are smoother across devices.
- **Topic hyperlinks.** Conversations can link to topics directly.
- **Message editing and deletion.** Editing and deleting messages behave more predictably.

## Improvements

- **Topic list interactions.** Interacting with the topic list is smoother.
- **Tool call display.** Tool calls are easier to read.
- **Rich text editing.** Editing behavior is refined.
- **Token usage statistics animations.** The usage animation is optimized.
- **Model selector sorting.** Models are ordered more sensibly.
