# 50+ New Models and 10+ Providers Added to the Ecosystem

## Features

- **10+ new providers.** Mainstream global and domestic platforms join the lineup, connectable from your existing LobeHub setup with no new setup steps.
- **DeepSeek R1 fully supported.** Parsing is consistent across providers, so reasoning output reads the same wherever the model runs.
- **Reasoning models expanded.** Claude 3.7 Sonnet and OpenAI o3-mini display their chain-of-thought in real time, so you can follow how a conclusion is reached.
- **Rebuilt online search.** SearchXNG and Perplexity integration plus deep web crawling let you research topics with live web results directly in chat, compare how providers handle the same query, and extract deeper content without leaving the conversation.
- **Native search in Gemini 2.0 and Qwen.** These models can use search as part of their reasoning process.
- **50+ model configurations refreshed.** OpenAI gpt-4.5-preview; Anthropic Claude 3.7 Sonnet and Haiku 3.5; Google Gemini 2.0 series improvements; Moonshot, Tongyi Qwen, and MiniMax latest models; and Perplexity, Cloudflare, and SiliconFlow refreshes.

## Improvements

- **More readable search results.** Result formatting is cleaned up.
- **Model parameters stay in sync.** Parameter synchronization across providers is improved.

## Fixes

- **Reasoning display is consistent.** The inconsistencies between model providers are resolved.
