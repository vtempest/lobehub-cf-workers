# Supported Models for Visual Recognition

## Features

- **Visual recognition models.** Conversations are no longer limited to text — OpenAI [`gpt-4-vision`](https://platform.openai.com/docs/guides/vision), Google Gemini Pro Vision, and Zhiyuan GLM-4 Vision are all supported.
- **Upload or drag images into chat.** Drop a screenshot, photo, diagram, or any visual reference into the chat window and your Agent understands it in context.
- **Everyday and professional use.** Share photos from your day and discuss them, upload UI screenshots for design feedback, get diagrams explained, or reference visual content without describing it in words.
- **Context-aware visual understanding.** The Agent doesn't just see an image — it reads it inside the ongoing conversation, so you can ask follow-up questions about specific details, compare multiple images, or use visuals as reference material for a longer discussion.
- **Clearer context for specialized fields.** Medical imaging discussions, architectural reviews, and technical diagram analysis all get more practical answers when both sides can see the same reference.
- **Voice options for personalized interaction.** Quality voices from OpenAI Audio and Microsoft Edge Speech let you pick one that fits your style or scenario.
