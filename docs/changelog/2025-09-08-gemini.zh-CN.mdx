# Gemini 图像生成与非流式模式支持 🎨

## 新功能

- **Gemini 2.5 Flash Image（Nano Banana）与 Imagen 4 GA。** 可直接在对话中通过 Gemini 模型生成图像。
- **新增 Nebius、AkashChat、BFL 覆盖。** 图像请求可路由到更多新上线的服务商。
- **Azure OpenAI 支持图像生成。** Azure OpenAI 现可处理图像生成请求。
- **非流式响应模式。** 适合需要完整响应后再展示的场景 —— 批处理、结构化输出，或期望同步结果的集成场景；可按使用场景在流式与完整响应间切换。
- **模型库更新。** 新增 GPT-5 系列、Claude Opus 4.1、Grok Code Fast 1、DeepSeek V3.1，以及用于检索增强的 Gemini URL Context Tool。

## 体验优化

- **推理滚动遮罩。** 优化滚动时的遮罩效果。
- **会话切换快捷键。** 可用键盘在会话之间切换。
- **移动端表单控件。** 小屏幕上的控件更好用。
- **Gemini 错误提示。** 错误信息表达更清晰。
