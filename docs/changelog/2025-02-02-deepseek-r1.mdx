# DeepSeek R1 Integration with Chain-of-Thought Transparency

## Features

- **DeepSeek R1 support.** v1.49.12 adds the model across both Community and Cloud editions.
- **Chain-of-thought in view.** When the model works through a problem you see its reasoning unfold in real time instead of receiving only the final answer.
- **More collaborative problem solving.** Debugging a script, working through a math problem, or analyzing a complex topic becomes easier to steer — you can see where the model's logic matches your intent and where it needs clarification, with the reasoning display sitting inside the conversation flow rather than cluttering the interface.
- **How to start.** Upgrade to v1.49.12 or visit [LobeHub.com](https://LobeHub.com), select DeepSeek R1 from the model dropdown, and start a conversation.

## Improvements

- **Faster chain-of-thought rendering.** Long reasoning sequences render more efficiently.

## Fixes

- **Consistent reasoning display.** Reasoning content parsing is fixed so it renders the same across different response types.
