# Customizable Hotkeys, Data Export, and Provider Expansion

## Features

- **Customizable hotkeys.** Remap common actions to keys that match your habits instead of learning a preset layout.
- **Shortcuts for clearing and deleting.** New hotkeys cover clearing conversations and deleting messages, so keyboard-driven sessions need the mouse less often.
- **Data export for PgLite and PostgreSQL.** Back up conversations or migrate between installations without manual database operations — useful for archiving important histories, moving to a new device or server, or keeping a local backup alongside cloud storage.
- **Six new providers.** Xinference, Cohere, Search1API, Infini-AI, and PPIO join the existing provider selection flow with no additional configuration.
- **Dedicated reasoning content selector.** Chain-of-thought display is improved for Claude 3.7 and DeepSeek R1, making reasoning easier to read and navigate in long conversations.
- **Better web crawling.** Dedicated support for YouTube, Reddit, and WeChat Official Account links, improved short content extraction, and an additional Search1API crawler implementation for wider coverage.
- **Model library updates.** Google Gemini 2.5 Pro Experimental and Gemini 2.0 Flash variants, Anthropic context caching support, OpenAI gpt-4o-mini-tts, DeepSeek-V3-0324, Hunyuan-T1-Latest, QwQ, QVQ-Max, and Baidu Wenxin ernie-x1-32k-preview.

## Improvements

- **UI refinements.** Revamped Drawer styles, improved editor scrolling, and clipboard screenshot sharing.
- **Search enhancements.** Online search works with non-function-calling models including DeepSeek R1, and built-in web search is added for Wenxin and Hunyuan.
- **File handling.** EPUB chunking is supported and PDF processing is improved.
- **Performance.** Agent Runtime is refactored and the database core code is optimized.

## Fixes

- **LiteLLM streaming statistics.** Streaming stats are reported correctly.
- **Theme flickering.** The theme no longer flashes on load.
- **Knowledge base behavior.** Several knowledge base issues are resolved.
- **WeChat login.** Sign-in problems with WeChat are fixed.
