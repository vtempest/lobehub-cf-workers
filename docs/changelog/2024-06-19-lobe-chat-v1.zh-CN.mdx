# LobeHub 1.0：为持久化、多用户协作而生的新架构

## 新功能

- **服务端数据库。** 对话与助手不再局限于单个浏览器会话，从笔记本切换到台式机上下文无缝衔接，知识可以持续积累而非每次从零开始。0.x 时代依赖浏览器存储，快速简单但无法跨设备同步、无法构建知识库、无法与团队共享。
- **知识库。** 存储文档并在多轮对话中引用。
- **跨设备同步。** 在任何设备上精准续接上次的工作。
- **私有助手市场。** 在团队内共享专用助手。
- **对话历史。** 搜索和回顾过往讨论。
- **用户认证与管理。** 同时集成 next-auth 与 Clerk 作为认证提供商，多用户可在同一实例中工作，并拥有清晰的权限边界。
- **独立用户面板。** 设置界面重构为一个面板，统一整合身份、偏好与访问控制 —— 在同一处管理账户设置和 API 密钥、配置认证提供商、控制团队成员的工作空间权限，并在个人与团队上下文间切换。
- **LobeHub Cloud Beta。** 基于 1.0 架构的托管服务，服务端持久化、用户管理与知识库无需任何配置即可使用。Beta 期间每日名额有限，[可在此加入等待名单](https://lobehub.com)。

## 体验优化

- **核心存储迁移至 PostgreSQL。** 存储层不再依赖 localStorage。
- **数据库迁移系统。** 升级时自动完成表结构变更，确保平滑过渡。
- **安全的会话管理。** 会话采用安全令牌处理机制。
- **设置重构为用户面板。** 账户、偏好与权限设置集中在同一界面。
- **多认证提供商支持。** 认证层可接入多个提供商。
- **首屏加载更快。** 通过服务端渲染优化初始加载性能。
