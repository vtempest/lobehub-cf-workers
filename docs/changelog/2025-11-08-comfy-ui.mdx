# ComfyUI Integration and Knowledge Base Improvements ⭐

## Features

- **ComfyUI workflows in chat.** Teams using ComfyUI for image or video generation had to manage a separate environment; now existing visual pipelines run inside conversations, alongside your AI discussions.
- **PDF document export.** Archive conversations for compliance or share structured outputs with stakeholders who need offline copies.
- **Waterfall layout for knowledge bases.** Scanning hundreds of files is more efficient when browsing extensive collections.
- **Automatic archive extraction on upload.** Drop a ZIP file and the system unpacks it — no manual unzipping before importing.
- **New providers.** **Cerebras** and **CometAPI** join the lineup.
- **More image generation.** **SiliconFlow** and **Hunyuan Text-to-Image 3** are supported.
- **Model library additions.** **Claude Haiku 4.5**, **GPT-5 Pro**, **MiniMax-M2**, and **Imagen 4** for Vertex AI.

## Improvements

- **Rich text link rendering.** Links render more accurately.
- **Search experience.** Search is faster to use and easier to read.
- **Rich text editing can be turned off.** An option disables the rich editor.
- **Hotkeys for delete and regenerate.** Both actions have keyboard shortcuts.
- **Update notification behavior.** Update prompts are less intrusive.
