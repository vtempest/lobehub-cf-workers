# LobeHub v1.6：GPT-4o mini 成为默认模型选项

## 新功能

- **支持 GPT-4o mini。** OpenAI 全系列模型已升级至 GPT-4 架构，v1.6 跟进这一变化，正式支持 GPT-4o mini。
- **Cloud 默认模型升级。** LobeHub Cloud 以 GPT-4o mini 替代 GPT-3.5-turbo，从第一条消息起就获得更强的对话能力，且无需任何配置调整。
- **更小规模的 GPT-4 级智能。** 响应速度足以支撑实时交互，能力覆盖起草文案、分析数据、编程辅助与创意工作 —— 推理能力强于 GPT-3.5 又避免完整 GPT-4o 的延迟，是高频对话的成本优化选择，指令遵循与工具调用表现稳定。
- **最强能力仍随时可切换。** 面对复杂推理任务，可切换至完整 GPT-4o、Claude 3.5 Sonnet 或 Gemini 1.5 Pro。
- **Cloud 自动升级。** 新对话默认使用 GPT-4o mini，模型切换器会将新默认选项置顶，现有用户无需更改设置。Cloud 现已支持 GPT-4o mini（默认）、GPT-4o、Claude 3.5 Sonnet 与 Gemini 1.5 Pro。

## 体验优化

- **GPT-4o mini 配置就绪。** 随模型提供配置与参数默认值。
- **更新 Cloud 默认模型逻辑。** 默认模型选择适配新的模型阵容。
- **推荐选项更醒目。** 模型切换器突出显示推荐模型。

## 问题修复

- **新版 OpenAI 模型流式响应。** 修复相关边界情况下的流式输出问题。
