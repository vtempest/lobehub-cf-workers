# Folder Map

One line per folder — a map for finding code fast. Grouped by repository area.

> **This repository has no test suite.** All `*.test.*` / `*.spec.*` files,
> `__tests__/`, `__snapshots__/`, `__mocks__/`, `tests/`, `e2e/` and every
> `vitest.config.*` were removed, along with the CI workflows that ran them.
> The only exceptions are the self-tests of the agent tooling under `.agents/`.
> Everything removed is recoverable from git history.

## Repository root

| Folder | What it is |
| --- | --- |
| `apps/` | Deployable build targets — web, server, desktop, CLI, and two Workers micro-apps. |

| `scripts/` | Build, release, migration and codegen scripts invoked from `package.json`. |
| `public/` | Static assets served as-is — favicons, OG images, screenshots, app icons. |
| `plugins/` | Custom Vite plugins used by `vite.config.ts` (build-critical, not optional). |
| `patches/` | pnpm `patchedDependencies` diffs applied at install time. |
| `docker-compose/` | Compose stacks for local dev, self-host deploy and production. |
| `changelog/` | Historical release-notes data (`v0`/`v1`/`v2` JSON + archived markdown). |
| `.github/` | GitHub Actions workflows, issue/PR templates, CODEOWNERS, CI helper scripts. |
| `.agents/` | Agent skills, the `bun run check` engine, acceptance and chaos fixtures. |
